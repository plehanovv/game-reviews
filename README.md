# game-reviews

Учебный проект: каталог игр с оценками, рецензиями и личной библиотекой.
Корень проекта — эта папка; её же открывай в GoLand.

Мы разрабатываем проект вместе по шагам. Сейчас создан только технический
каркас. Пользователей, базы данных в коде, каталога, интерфейса сайта и
обработчиков Kafka ещё нет. Следующий шаг делает автор проекта, затем мы
обсуждаем код и проводим ревью. План: [docs/learning-plan.md](docs/learning-plan.md).

## Что уже создано и зачем

1. `go.mod` задаёт имя модуля и версию языка. `game-reviews` — локальное имя;
   после создания удалённого репозитория можно заменить его и импорты на его адрес.
   Минимум — Go 1.26; рекомендуемый toolchain — 1.27.1. Go может автоматически
   скачать его при первом запуске. На компьютере обнаружен Go 1.26.1.
2. `cmd/api/main.go` — точка входа. Она собирает конфигурацию и HTTP-сервер,
   пишет структурированные JSON-логи через `slog` и завершает текущие запросы
   при остановке. Таймауты ограничивают время работы соединений.
3. `internal/config` читает `HTTP_ADDR` из окружения и проверяет порт.
   По умолчанию сервер доступен только локально: `127.0.0.1:8080`.
   Папка `internal` ограничивает импорт пакетов извне проекта средствами Go.
4. `internal/httpapi` содержит маршруты стандартного `net/http`.
   `GET /healthz` возвращает `{"status":"ok"}`. Это проверка HTTP-процесса,
   а не готовности базы или брокера. Readiness добавим с реальными зависимостями.
5. Файлы `*_test.go` проверяют конфигурацию и HTTP-контракт без внешних сервисов.
6. `compose.yml` описывает локальные PostgreSQL, Redis и Kafka в режиме KRaft,
   без ZooKeeper. PostgreSQL и Kafka используют именованные volumes для данных.
   Redis настроен как удаляемый кэш, без сохранения на диск. Порты опубликованы
   только на localhost. Это учебное локальное окружение, не production-конфигурация.
7. `Dockerfile` собирает Go-бинарник отдельным этапом, затем помещает его
   в минимальный образ с непривилегированным пользователем. Пока приложению
   не нужны сертификаты и другие файлы ОС; при внешних HTTPS-запросах добавим CA.
8. `.env.example` — пример переменных для Compose. `.env` исключён из Git.
   Само Go-приложение `.env` не читает: переменные для него задаются в процессе
   или в конфигурации запуска GoLand.
9. `.gitignore`, `.dockerignore`, `.gitattributes` исключают локальные файлы
   и задают окончания строк. `.github/workflows/ci.yml` описывает проверки
   форматирования, `vet`, тесты с race detector и сборку для GitHub Actions.
   Удалённый репозиторий и Git-коммиты пока не создавались.

## Первый запуск: без Docker

В терминале GoLand, из корня проекта:

```powershell
go run ./cmd/api
```

В другом терминале:

```powershell
Invoke-RestMethod http://127.0.0.1:8080/healthz
go test ./...
go vet ./...
```

Остановка — Ctrl+C. В GoLand можно запустить `main` зелёной кнопкой рядом
с функцией; working directory должен указывать на корень проекта.
Если загрузка рекомендуемого toolchain недоступна, текущий каркас совместим
с установленным Go 1.26.1: `$env:GOTOOLCHAIN='local'` для текущего терминала.
Это временный вариант, а не обновление Go.

## Инфраструктура: позже, на шаге PostgreSQL

Сейчас запускать все сервисы для первого задания не нужно.
Docker CLI установлен, но при проверке Docker Engine был недоступен.
Перед командами ниже запусти Docker Desktop с Linux containers.

```powershell
Copy-Item .env.example .env
docker compose config --quiet
docker compose up -d postgres
docker compose ps
```

Копируй `.env.example` только если своего `.env` ещё нет. Пароль в примере
предназначен исключительно для локальной разработки.
Когда дойдём до Redis и Kafka:

```powershell
docker compose up -d redis kafka
```

Для запуска API в контейнере вместо GoLand:

```powershell
docker compose --profile app up -d --build
```

Не запускай одновременно два API на порту 8080. API пока не обращается
к сервисам: запуск контейнеров сам по себе не означает интеграцию.
Из GoLand адреса сервисов — `localhost:5432`, `localhost:6379`, `localhost:9092`.
Из контейнеров — `postgres:5432`, `redis:6379`, `kafka:29092`.
Остановить окружение с сохранением данных: `docker compose --profile app down`.
Флаг `-v` удаляет volumes с данными; для обычной остановки он не нужен.

## Версии

Версии в Dockerfile/Compose закреплены, тег `latest` не используется.
Ориентиры проверены по официальным страницам 7 октября 2026:

- [Go 1.27.1](https://go.dev/dl/).
- [PostgreSQL 18.6](https://www.postgresql.org/docs/release/).
- [Kafka 4.3.1](https://kafka.apache.org/community/downloads/).
- [Redis 8.10.2](https://download.redis.io/releases/).

Проверка страниц релизов не заменяет загрузку Docker-образов и интеграционные
тесты: их запуск пока не проверен из-за недоступного Docker Engine.
Обновления будем делать отдельным осмысленным изменением с проверками.
